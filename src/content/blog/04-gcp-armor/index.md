While exploring Google Cloud Armor, Google's web security service, I stumbled upon 
[this brilliant video](https://www.youtube.com/watch?v=RsXbmOb3L2E) on Youtube.

The video demonstrates how Cloud Armor acts as a security shield for your applications, 
protecting them from DDoS attacks and other security threats. I was quite impressed 
to see the real-time demonstration of its features. What's more interesting is that 
it comes with out-of-the-box support for [OWASP top 10](https://owasp.org/www-project-top-ten/) 
security risks, which is jolly good for securing web applications.
